# Telangana Rice Mill Transaction Analytics

## Big Data Analytics Project | BSM PGDM 2026

### Project Overview
This project focuses on analyzing rice mill transaction data from Telangana using Big Data Analytics tools and technologies. The objective is to organize transaction records, analyze business trends, and generate meaningful insights to support data-driven decision-making.

The project uses a **synthetic dataset of 100,000 rice mill transaction records** for analytical and educational purposes.

### Project Objectives
- Analyze rice mill transaction data.
- Perform data cleaning and preprocessing.
- Store and query structured data using PostgreSQL.
- Explore large datasets using PySpark.
- Understand Delta Lake for data storage and processing.
- Develop visualizations and dashboards using Power BI.
- Generate insights to support business decisions.

### Technologies Used
- Python
- Pandas
- PostgreSQL
- DBeaver
- Databricks
- PySpark
- Delta Lake
- Power BI
- GitHub

### Project Workflow
1. Dataset preparation
2. Data cleaning and preprocessing
3. Database design and SQL analysis
4. Big data processing using PySpark
5. Data storage and transformation
6. Visualization and reporting
7. Business insights and recommendations

### Repository Structure
The project files will be organized into folders for the dataset, Python scripts, SQL queries, notebooks, reports, and documentation.

### Dataset Information
The project uses a synthetic dataset containing 100,000 transaction records. It is intended for educational analysis and does not represent verified real-world rice mill transactions.

### Expected Outcomes
- Better understanding of transaction data.
- Practice with SQL and big data processing.
- Identification of analytical trends in the dataset.
- Business-focused reporting and visualization.
